# 📊 Tableau Project – Data Visualisation & Dashboard Development

*A hands-on project demonstrating my ability to analyse data and design insights using Tableau*

## 🔍 Overview

This repository contains my work from a Tableau-focused training week within the Data Technician programme.

The project showcases how I use Tableau Desktop and Tableau Public to build interactive dashboards, explore datasets, identify trends, and communicate insights visually.

## 🚀 Skills Demonstrated

### ✔️ Tableau Dashboard Design

* Building multi-chart dashboards
* Combining bar charts, pie charts, maps, and filters
* Adding interactive filters (Country, Continent, Gender, Year)
* Publishing and sharing dashboards on Tableau Public

### ✔️ Data Visualisation Techniques

* Bar charts
* Line charts
* Pie charts
* Scatter plots
* Map visualisation (UK cities)
* Using colour, sorting, and labels for storytelling

### ✔️ Calculated Fields & Filters

* Calculated fields such as Total Cancer Cases and Cancer Case Rate
* Top N filter (top 5 countries by life expectancy)
* Single-value dropdown filter for country selection

### ✔️ Data Analysis

* Identifying patterns and trends across large datasets
* Understanding relationships such as:
  * Life expectancy vs BMI (Health dataset)
  * Popularity vs value (Spotify dataset)
  * Job change by city and industry (EMSI dataset)
* Interpreting datasets to support decision-making

### ✔️ Tableau Versions

* Differences between:
  * Tableau Public
  * Tableau Desktop
  * Tableau Cloud
  * Tableau Server

## 📁 Project Contents

* EMSI Job Change analysis (bar charts, pie chart + UK map)
* Global Health dashboard (Gapminder dataset)
* Spotify dataset dashboard & insights
* Screenshots of dashboards created

## 🧠 Key Learning Outcomes

Throughout this Tableau project, I strengthened my ability to:

* Turn raw data into interactive dashboards
* Build maps and location-based visualisations
* Present insights in a compelling visual format
* Use filters and calculated fields to explore data
* Communicate complex analysis clearly

For example:

* Health Dataset: Europe has the highest average life expectancy (75.4 years) and Africa the lowest (55.1).
* Spotify Data: Popularity is not necessarily indicative of value, across both genre and artist.

## 🛠 Tools Used

* Tableau Desktop
* Tableau Public
* Tableau mapping features
* Microsoft Excel (source datasets)
